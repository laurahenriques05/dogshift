# Walk history and statistics

Past Adventures at /walks?view=history lists real completed nondeleted walks from
the last 168 hours, newest first, with period filters and 20-entry pagination.
Month is default; dates use the household time zone and Monday-based weeks.
An empty selected period differs from having no saved history. History rows use
the saved member display name followed by 's Walk, with an honest fallback.

Last Adventure shows the latest eligible real walk, or the message Your first
completed walk will appear here. Walking together shows real completed totals,
kilometres and pause-adjusted duration, with distance/time charts visible by
default and a text toggle. No count chart or invented empty-state statistics.
Manual circles and active/deleted walks do not inflate recorded-walk totals.

Demo walks, Deleted/Not deleted filters, restore/remove crosses and automatic area
naming are removed. Old demo URLs return to real history; synthetic helpers/tests
are internal only. Do not expose them again. The historical filename is retained
for existing links. Physical retention is installed; see carol-walks-team-sync.md.
